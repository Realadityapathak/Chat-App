# Database Schema

Database engine: MongoDB (Mongoose ODM v8.10.1)

---

## 1. `users` Collection

Defined in [`backend/src/models/User.js`](file:///c:/Users/ADITYA%20PATHAK/Chat-App/backend/src/models/User.js)

### Schema Definition
```javascript
{
  email: {
    type: String,
    required: true,
    unique: true,
    lowercase: true,
    trim: true,
  },
  fullName: {
    type: String,
    required: true,
    trim: true,
  },
  password: {
    type: String,
    required: true,
    minlength: 6,
  },
  profilePic: {
    type: String,
    default: "",
  },
  createdAt: Date, // generated by timestamps: true
  updatedAt: Date  // generated by timestamps: true
}
```

### Fields
| Field | Type | Required | Unique | Default | Notes |
|---|---|---|---|---|---|
| `_id` | ObjectId | Yes (Auto) | Yes | Auto-generated | MongoDB primary key |
| `email` | String | Yes | Yes | None | Normalized with lowercase and trim |
| `fullName` | String | Yes | No | None | Normalized with trim |
| `password` | String | Yes | No | None | Stored as bcrypt hash (minlength: 6) |
| `profilePic` | String | No | No | `""` | Hosted URL from Cloudinary |
| `createdAt` | Date | Yes (Auto) | No | Date.now | Managed by Mongoose timestamps |
| `updatedAt` | Date | Yes (Auto) | No | Date.now | Managed by Mongoose timestamps |

### Indexes
- `{ email: 1 }` (Unique index enforced by MongoDB / Mongoose)

## 2. `messages` Collection

Defined in [`backend/src/models/Message.js`](file:///c:/Users/ADITYA%20PATHAK/Chat-App/backend/src/models/Message.js)

### Schema Definition
```javascript
{
  senderId: {
    type: mongoose.Schema.Types.ObjectId,
    ref: "User",
    required: true,
  },
  receiverId: {
    type: mongoose.Schema.Types.ObjectId,
    ref: "User",
    required: true,
  },
  text: {
    type: String,
  },
  image: {
    type: String,
  },
  createdAt: Date, // generated by timestamps: true
  updatedAt: Date  // generated by timestamps: true
}
```

### Fields
| Field | Type | Required | Unique | Default | Notes |
|---|---|---|---|---|---|
| `_id` | ObjectId | Yes (Auto) | Yes | Auto-generated | MongoDB primary key |
| `senderId` | ObjectId | Yes | No | None | References `User._id` |
| `receiverId` | ObjectId | Yes | No | None | References `User._id` |
| `text` | String | No | No | undefined | Message text content |
| `image` | String | No | No | undefined | Hosted URL from Cloudinary |
| `createdAt` | Date | Yes (Auto) | No | Date.now | Managed by Mongoose timestamps |
| `updatedAt` | Date | Yes (Auto) | No | Date.now | Managed by Mongoose timestamps |

### Indexes
- Primary Key: `_id_`
- Compound Index 1: `{ senderId: 1, receiverId: 1, createdAt: 1 }`
- Compound Index 2: `{ receiverId: 1, senderId: 1, createdAt: 1 }`

---

## Relationships
- `senderId` -> Foreign Key referencing `User._id`
- `receiverId` -> Foreign Key referencing `User._id`
